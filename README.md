# 식사 · 식후 · 산책

상암 누리꿈스퀘어를 기본 출발지로, 인원수에 맞는 식당 → 식후(카페·디저트) → 산책/실내 코스를 고르는 페이지입니다.

누리꿈스퀘어 1.5km 안은 `data/sangam.json`(2026-11-27 조사)을 쓰고, 그 밖은 OpenStreetMap 식당(`restaurants.json`)으로 넘어갑니다. 그 경우 인원 맞춤은 추정입니다. 상암 밖 카페·디저트는 조사 자료가 없어 보여 주지 않습니다.

메뉴·가격이 자료에 없으면 메뉴 칸을 만들지 않습니다. 카드의 가봤어요와 먹은 메뉴는 이 브라우저의 localStorage에만 저장되고, 내 기록에서 JSON으로 내보내거나 가져올 수 있습니다. `excluded`에 있는 장소는 화면에 나오지 않습니다.

```bash
python3 -m http.server 8765
npx playwright test
```
