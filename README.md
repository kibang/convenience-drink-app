# 🥤 내 주변 혼밥 · 편의점 음료

내 위치(또는 입력한 주소/좌표) 주변의 CU · GS25 · 세븐일레븐 · 이마트24 매장을 거리순으로 보여주고,
각 편의점 공식 행사 페이지에서 수집한 **음료 행사 상품**을 장르·가격대·행사유형·브랜드·증정(굿즈) 여부로 걸러 볼 수 있는 단일 페이지 웹앱입니다.

## 사용법
1. `index.html`을 더블클릭해 브라우저로 엽니다. (data.js가 함께 있어야 합니다. 매장·식당 JSON은 http 서버에서 불러옵니다)
2. **현재 위치 사용**을 누르거나, 주소(예: `강남역`, `아리랑로19길`) 또는 좌표(예: `37.5665,126.9780`)를 입력 후 **검색**.
   위쪽 지도에 내 위치와 반경이 표시됩니다. 처음 탭 **혼밥+음료**에서는 주변 식당 마커가, **편의점** 탭에서는 편의점 마커가 나옵니다.
   - 브라우저가 file:// 에서 위치 권한을 막으면 주소/좌표 입력을 쓰거나, 폴더에서 `python3 -m http.server 8000` 실행 후 http://localhost:8000 으로 여세요.
3. 장르(커피/탄산/주스/차/에너지·이온/우유·두유/생수/주류), 가격대, 행사유형(1+1, 2+1, 3+1, 할인, 골라담기, 덤증정), 브랜드, 증정·굿즈 토글로 필터링.
4. 각 상품 카드에 해당 브랜드의 가까운 매장 3곳이 표시됩니다.
5. **혼밥+음료**(첫 탭): 식당을 고르면 음식 종류에 맞춘 편의점 음료 행사를 보여 줍니다. 가격·행사·장르는 수집된 행사 상품 그대로이고, 그 브랜드의 가까운 매장 거리가 있으면 같이 보여 줍니다. **행사 보기**를 누르면 편의점 탭에서 그 브랜드 행사만 남습니다. 조합은 설명 가능한 규칙이며 건강 효과가 아닙니다.
   - 매운 상호(떡볶이·마라·짬뽕 등) → 우유/두유·차·생수
   - 버거·샌드위치 → 탄산·커피
   - 면·라면 → 생수·차·우유/두유
   - 분식·김밥 → 우유/두유·차·탄산
   - 초밥 → 차·생수·탄산
   - 밥·국밥 → 탄산·차·생수
   - 패스트푸드·푸드코트 → 탄산·커피·주스
   - 간편식 → 커피·생수·차
6. **편의점** 탭은 기존 음료 필터입니다. 마커를 누르면 그 브랜드 행사만 남고 해당 매장이 강조됩니다.
7. **식당** 탭은 혼밥 추정 식당만 봅니다. 혼밥 가능은 업종·요리 추정이며 매장 확인이 아닙니다. 각 카드의 **메뉴·가격**을 열면, 자료가 없을 때 `등록된 메뉴·가격 정보 없음`이라고 나옵니다. 메뉴·가격을 만들지 않습니다. OSM 2026-11-05 추출본의 혼밥 추정 식당에는 메뉴 가격이 없고, 2026-11-06 맥도날드 코리아 공개 목록도 가격이 없어 브랜드 대표 가격을 넣지 않았습니다.

## 지도와 혼밥 식당
- 지도는 Leaflet + OpenStreetMap 타일(키 없음)입니다. 저작권 표시는 지도 안과 지도 아래에 있습니다.
- 편의점 마커를 누르면 그 브랜드(CU·GS25·세븐일레븐·이마트24) 행사만 필터되고, 상품 카드와 매장 목록에서 그 매장이 강조됩니다. 기타 편의점은 행사 데이터와 연결되지 않는다고 안내합니다.
- 식당 자료는 `restaurants.json`입니다. 실시간 Overpass 대신 Geofabrik 대한민국 추출본(2026-11-05)에서 추린 전국 데이터라서, 반경을 바꿔도 외부 식당 API를 기다리지 않습니다.
- 사진: 그 식당 OSM `image` 태그가 있을 때만 매장 사진입니다. 이 추출본의 혼밥 추정 식당에는 그 태그가 없습니다. 브랜드 위키데이터 로고는 **브랜드 대표 이미지 · 이 매장 사진이 아님**, 다른 지점 사진은 **다른 지점·브랜드 사진**, 없으면 **등록된 매장 사진 없음**입니다. 일반 음식 사진은 매장 사진으로 넣지 않습니다.
- 식당 JSON을 다시 만들려면 `pip install osmium` 후 `python3 build_restaurants.py /tmp/south-korea.osm.pbf restaurants.json`.

⚠️ 행사는 **전국 공통 행사** 기준이며 **매장별 재고는 보장되지 않습니다.** 방문 전 매장/앱에서 확인하세요.

## 데이터 출처
- 매장 위치: `stores.json`에 넣은 OpenStreetMap 전국 편의점(2026-11-05, `shop=convenience` + 브랜드/이름 매칭). 파일을 못 읽으면 그 반경만 Overpass로 조회합니다. 주소 검색: Nominatim / Photon.
  - OSM은 일부 매장이 누락될 수 있습니다. **카카오 로컬 API 키**(REST 키)를 쓰면 매장 커버리지가 훨씬 정확해집니다(키워드 "CU" 등 반경 검색).
- 행사 상품: CU(cu.bgfretail.com 행사상품), 세븐일레븐(7-eleven.co.kr 행사상품), 이마트24(emart24.co.kr 행사상품, 음료 카테고리)
- GS25: 공식 홈페이지 행사상품 페이지가 오류(500)로 응답하며, 2026년 9월부터 행사 목록이 '우리동네GS' 앱 전용으로 바뀐 것으로 보여 **수집 불가**. 앱 화면에도 실패로 표시됩니다. (임의 데이터는 넣지 않습니다)
- 장르는 상품명 키워드로 자동 분류하므로 일부 오분류가 있을 수 있습니다.
- 증정/굿즈 정보는 공식 페이지에 표기된 경우(덤증정 탭 등)만 표시됩니다.

## 데이터 새로고침 (매월 1일 행사 변경 시)
```bash
pip install requests beautifulsoup4 playwright && python3 -m playwright install chromium
python3 scraper.py              # 전체 체인 다시 수집 → data.json, data.js 갱신
python3 scraper.py 7-Eleven     # 특정 체인만 다시 수집 (나머지는 기존 데이터 유지)
```
세븐일레븐 서버는 응답이 느리고 끊김이 잦아 수집에 10~30분 걸릴 수 있습니다.

## 파일
- `index.html` 앱 / `data.json` 수집 데이터 / `data.js` (file://로 열 때 쓰는 같은 데이터) / `stores.json` 전국 편의점 / `restaurants.json` 전국 혼밥 추정 식당 / `scraper.py` 수집기 / `build_restaurants.py` 식당 묶음 / `vendor/leaflet` 지도 라이브러리
- 모바일 확인: `npm install` 후 `npx playwright test` (Chromium/Chrome, 390px, 서울시청·아리랑로19길 위치 모킹)
