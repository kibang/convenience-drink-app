# 🥤 내 주변 편의점 음료 행사 찾기

내 위치(또는 입력한 주소/좌표) 주변의 CU · GS25 · 세븐일레븐 · 이마트24 매장을 거리순으로 보여주고,
각 편의점 공식 행사 페이지에서 수집한 **음료 행사 상품**을 장르·가격대·행사유형·브랜드·증정(굿즈) 여부로 걸러 볼 수 있는 단일 페이지 웹앱입니다.

## 사용법
1. `index.html`을 더블클릭해 브라우저로 엽니다. (data.js가 함께 있어야 합니다)
2. **현재 위치 사용**을 누르거나, 주소(예: `강남역`) 또는 좌표(예: `37.5665,126.9780`)를 입력 후 **검색**.
   - 브라우저가 file:// 에서 위치 권한을 막으면 주소/좌표 입력을 쓰거나, 폴더에서 `python3 -m http.server 8000` 실행 후 http://localhost:8000 으로 여세요.
3. 장르(커피/탄산/주스/차/에너지·이온/우유·두유/생수/주류), 가격대, 행사유형(1+1, 2+1, 3+1, 할인, 골라담기, 덤증정), 브랜드, 증정·굿즈 토글로 필터링.
4. 각 상품 카드에 해당 브랜드의 가까운 매장 3곳이 표시됩니다.

⚠️ 행사는 **전국 공통 행사** 기준이며 **매장별 재고는 보장되지 않습니다.** 방문 전 매장/앱에서 확인하세요.

## 데이터 출처
- 매장 위치: OpenStreetMap Overpass API (`shop=convenience` + 브랜드/이름 매칭, 키 불필요). 주소 검색: Nominatim.
  - OSM은 일부 매장이 누락될 수 있습니다. **카카오 로컬 API 키**(REST 키)를 쓰면 매장 커버리지가 훨씬 정확해집니다(키워드 "CU" 등 반경 검색).
- 행사 상품: CU(cu.bgfretail.com 행사상품), 세븐일레븐(7-eleven.co.kr 행사상품), 이마트24(emart24.co.kr 행사상품, 음료 카테고리)
- GS25: 공식 홈페이지 행사상품 페이지가 오류(500)로 응답하며, 2026년 9월부터 행사 목록이 '우리동네GS' 앱 전용으로 바뀐 것으로 보여 **수집 불가**. 앱 화면에도 실패로 표시됩니다. (임의 데이터는 넣지 않습니다)
- 장르는 상품명 키워드로 자동 분류하므로 일부 오분류가 있을 수 있습니다.
- 증정/굿즈 정보는 공식 페이지에 표기된 경우(덤증정 탭 등)만 표시됩니다.

## 데이터 새로고침 (매월 1일 행사 변경 시)
```bash
pip install requests beautifulsoup4 playwright && python3 -m playwright install chromium
python3 scraper.py              # 전체 체인 다시 수집 → data.json, data.js 갱신
python3 scraper.py 7-Eleven     # 특정 체인만 다시 수집 (나머지는 기존 데이터 유지)
```
세븐일레븐 서버는 응답이 느리고 끊김이 잦아 수집에 10~30분 걸릴 수 있습니다.
